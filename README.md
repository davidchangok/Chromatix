# Chromatix

[![Version](https://img.shields.io/badge/Version-1.1-blue)](https://github.com/davidchangok/Chromatix)
[![Interface](https://img.shields.io/badge/Interface-120000-orange)](#)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

**Chromatix** is a World of Warcraft addon that automatically equips gear sets based on your current specialization.

## Features

- **Auto Swap**: Automatically equips the linked gear set when you change specializations.
- **One-Click Creation**: Adds a "New Spec Set" button to the Equipment Manager to quickly create a set named after your current spec.
- **Smart Naming**: Supports English (e.g., "Retribution") or Localized (e.g., "惩戒") naming conventions.
- **Combat Protection**: Swaps triggered during combat are deferred until combat ends.

## Commands

| Command | Description |
|---|---|
| `/chromatix` / `/ctx` | Show available commands |
| `/chromatix config` | Open settings panel |
| `/chromatix status` | Show current spec and linked set |
| `/chromatix swap` | Manually trigger gear swap for current spec |
| `/chromatix save` | Save current gear to the active spec's set |
| `/chromatix debug` | Toggle debug mode |
| `/chromatix reset` | Reset current character settings |

## Installation

1. Download from [GitHub Releases](https://github.com/davidchangok/Chromatix/releases).
2. Extract the `Chromatix` folder to your WoW directory: `_retail_\Interface\AddOns\`.

# Chromatix (幻色龙)

## 简介

Chromatix 是一个魔兽世界插件，旨在根据你当前的专精（Specialization）自动切换装备方案（Equipment Set）。

## 功能

- **自动切换**: 切换专精时自动装备关联的套装。
- **一键创建**: 在装备管理界面增加"新的天赋方案"按钮，快速创建以当前专精命名的套装。
- **智能命名**: 支持英文（如 "Retribution"）或本地化（如 "惩戒"）命名方式。
- **战斗保护**: 战斗中触发的切换操作会自动延迟到战斗结束后执行。

## 命令

| 命令 | 说明 |
|---|---|
| `/chromatix` / `/ctx` | 查看可用命令列表 |
| `/chromatix config` | 打开设置面板 |
| `/chromatix status` | 显示当前专精及关联套装 |
| `/chromatix swap` | 手动触发当前专精的装备切换 |
| `/chromatix save` | 将当前装备保存到当前专精对应的套装中 |
| `/chromatix debug` | 切换调试模式 |
| `/chromatix reset` | 重置当前角色设置 |

## 安装

1. 从 [GitHub Releases](https://github.com/davidchangok/Chromatix/releases) 下载。
2. 将 `Chromatix` 文件夹放置于 `_retail_\Interface\AddOns\` 目录下。
